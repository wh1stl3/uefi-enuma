# Native status and two-window frame observation

Step17 requires MDSS version major 6 and checks bit0 of DSI INTF_STATUS at +0x26c on both saved enuma blocks. Step18 follows the pinned Xiaomi v1 get_status counter-read contract after that actual-active predicate. The source is Xiaomi_Kernel_OpenSource 52a2f180865f8368828985d6384130acd093fa93, techpack/display/msm/sde/sde_hw_intf.c; its catalog selects this status operation for hardware major 5/6. The version location is the matching sde_kms.c core_rev read at mmio+0. All accesses stay inside the existing R-004 MDP mapping.

This is a new observation contract, not a redefinition of historical step15/16. The old requirement that FRAME_LINE_COUNT_EN low bits equal 3 tested the Linux full-configuration value; native get_status reads counters when INTF_STATUS bit0 is set and has no such check. Step18 records enable/timing stability without asserting their numeric values or writing them. Disabled/constant counters still cannot pass a changing-value observation.

At most 26 MMIO reads and two existing Boot Services Stall(100000) calls. For each originally active interface, each frame sample must not decrease or advance by more than 64; active bit0 stays set, and original timing/enable words stay unchanged. At least one SAME interface must advance by 1..64 in EACH of the two windows. Version is checked again unchanged. Wrap, reset/decrease, oversized delta, changed configuration, inactive status and any wait failure/warning refuse. No active interface means no counter sampling or waiting. Unsupported major means no interface accesses.

Success supports repeated bounded frame-counter progress in an active interface. It does not prove SSPP routing, panel/backlight, pixels, physical/IOVA identity, exact display frequency or a measured 100ms duration. Non-atomic samples cannot rule out transient reconfiguration or carefully coincident resets. Runtime complementary timing is not a numeric register dump. No new map, library, constructor, framebuffer access, MMIO write or verification flag is introduced. R-005 remains consumed.
